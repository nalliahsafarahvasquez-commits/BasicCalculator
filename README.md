# Basic Calculator

A simple calculator application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* User-friendly interface
* Handles basic arithmetic calculations

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the calculator.

## Project Structure

```text
Basic-Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

The calculator accepts numerical input and allows users to perform basic mathematical operations.

### Supported Operations

| Operation      | Symbol |
| -------------- | ------ |
| Addition       | `+`    |
| Subtraction    | `-`    |
| Multiplication | `×`    |
| Division       | `÷`    |

## Example

```text
10 + 5 = 15
20 - 8 = 12
6 × 4 = 24
20 ÷ 5 = 4
```
